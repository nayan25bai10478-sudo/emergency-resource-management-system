# Project Statement

## Problem Statement

During an emergency, information about incidents and available resources can become difficult to manage manually. A simple system is needed to record incidents, set their priority, check available resources and assign resources.

## Scope

This project is made for a small campus, office or similar setup. It works through the command line and stores basic data in local text files.

## Target Users

- Campus emergency teams
- Security teams
- Small office response teams
- Resource coordinators

## High-Level Features

- Add and view incidents
- Set incident priority
- Add and view resources
- Check available resources
- Assign resources
- Update incident status
- View system summary
- Validate user input
